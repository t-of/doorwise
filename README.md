# DOORWISE — 扉を開けて泥棒を追いつめる

光っている扉のどれかに泥棒が隠れている。扉を開けるたびに泥棒は音から遠ざかって逃げるので、開けた扉を壁にして追いこみ、光を最後の 1 枚まで減らす。全 12 ステージ。

## 🔗 リンク

- 遊ぶ: https://t-of.github.io/doorwise/
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方

1. 光っている扉のどれかに泥棒が隠れている。扉を押すと開いて、開いたまま壁になる。
2. 扉が開くと、泥棒は音から遠ざかるほうへ 1 マス逃げる（上下左右）。光もそれに合わせて動く。
3. 光を最後の 1 枚まで減らしたら、泥棒をつかまえてクリア。少ない手数ほどよい。

- 遠ざかる = 開けた扉からの道のり（閉じた扉だけを通る歩数）が 1 増えるとなり。行けるとなりが複数あれば、光はその全部に広がる。行けなければ動かない（隅・袋小路）。
- 音は開いた扉と壁を越えない。道がつながっていない所の泥棒は動かない。
- 泥棒はずる賢いので、光が 1 枚になるまで見つからない。1 枚になると自動で開いてつかまえる。
- 全 12 ステージ。目標手数以内で ★3、+2 手以内で ★2。1 手もどす・はじめからがある。
- キーボード: `Z` / `Backspace` で 1 手もどす、`R` ではじめから。

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
node test/check.mjs           # 自己チェック（10 秒ほど）
```

| ファイル | 中身 |
|---|---|
| `logic.js` | 決まりごと（道のり、逃げる、光、つかまえる、保存データの読み直し）。画面に触らない |
| `stages.js` | 12 ステージの形・目標手数・その手順 |
| `main.js` | 画面・音・保存 |
| `test/solve.mjs` | 探索（ビーム探索、全部の手を調べる探索、欲ばり、でたらめ） |
| `test/check.mjs` | ルールの見本、本当の泥棒がいつも光の中にいるか、詰みがないか、ステージの手数と遊びになっているかの条件 |

局面は「閉じた扉」と「光っている扉」の 2 つで決まり、乱数はない。ステージを変えたら `node test/check.mjs` を回し、
目標手数と手順が探索の結果と合わなければ `stages.js` を直す。

条件: 一番よい手数が 2〜14 手、でたらめの平均の半分以下、ステージ 5 から先は欲ばり（1 手先で光が一番減る扉）≥ 一番よい + 1、
1 つ前より 2 手以上減らない、袋小路は 2 つまで。
